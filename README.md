# Linux Doctor

Инструмент для диагностики и автоматического исправления ошибок в системах Linux.

## Пошаговая установка и запуск

Выполняйте команды в терминале строго по очереди:

### Шаг 1. Скачивание пакета
Скачивает готовый установочный `.deb` пакет напрямую из репозитория GitHub. Ссылка обернута в кавычки, чтобы избежать ошибок интерпретации спецсимволов в оболочке `zsh`:
```bash
wget "https://raw.githubusercontent.com/shamil13/linux-doctor/main/linux-doctor.deb"
```

### Шаг 2. Обновление индексов пакетов
Обновляет списки пакетов в системе, чтобы менеджер пакетов знал актуальные пути к системным зависимостям:
```bash
sudo apt update
```

### Шаг 3. Установка утилиты
Устанавливает скачанный пакет в систему. Менеджер `apt` автоматически определит и докачает из интернета все необходимые для работы утилиты зависимости (например, нужные библиотеки Python):
```bash
sudo apt install ./linux-doctor.deb
```

### Шаг 4. Удаление инсталлятора
Удаляет временный файл `linux-doctor.deb` из текущей папки, так как программа уже успешно скопирована в систему и установочный архив больше не нужен:
```bash
rm linux-doctor.deb
```

### Шаг 5. Проверка работы и просмотр флагов
Запускает установленную утилиту с флагом вызова справки. Команда выведет в терминал список всех доступных опций, настроек и ключей автоматизации:
```bash
linux-doctor --help
```

---

## Полное удаление утилиты

Если вам потребуется полностью удалить программу и все связанные с ней конфигурационные файлы из операционной системы, выполните:
```bash
sudo apt purge linux-doctor
```
